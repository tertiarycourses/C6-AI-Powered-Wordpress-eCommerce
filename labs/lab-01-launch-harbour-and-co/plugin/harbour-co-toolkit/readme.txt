Course plugin for Build a Professional eCommerce Store with Generative AI (C6). Adds the Harbour & Co brand styles, five
block patterns (Hero banner, Three collections, New arrivals grid, Trust bar, Policy links) and an
optional block editor for WooCommerce products (Settings > Harbour & Co). Shows SGD prices as S$.

== Installation ==
Plugins > Add Plugin > Upload Plugin > choose harbour-co-toolkit.zip > Install Now > Activate Plugin.

Tested with WordPress 7.1.4, WooCommerce 11.2.1 and Storefront 4.6.2.
